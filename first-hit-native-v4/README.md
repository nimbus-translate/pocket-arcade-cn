# 数位首现汇聚谱 4.0 · 原生 Android 实验室

Android 8.0+ 原生 Java 应用。新包名 `io.firsthit.studio.v4`，避免与旧版 APK 的测试签名冲突，可以与 v3 并存。

## 两个实时可切换计算模式

- **流畅优先（默认）**：限制同时搜索的样本线程为 `max(1,min(3,(CPU线程数-1)/2))`，长搜索每 64 位检查暂停并短暂礼让 CPU，图表约 180 ms 批量刷新一次。此模式优先保持手机的触摸、滚动、动画响应；效果仍受机型、系统和散热影响。
- **全速运算**：允许使用系统报告的所有逻辑 CPU 核心，降低计算礼让时间。可能带来界面卡顿、温升或更高耗电；操作系统仍保留调度权，并不保证“占满”所有性能。

运行过程中直接点击两个模式即可切换，`Signal` 动态调整允许的并发任务数。已经运行中的样本搜索不会被丢弃，进入限制后新的样本会等待；长搜索也会响应模式变更。

## 交互图表

5 个 16:10 原生 Canvas 统计图：累计汇聚曲线、近期汇聚、分布直方图、100 样本分组均值、最近 96 条命中位置热力矩阵。支持触控、曲线双指缩放、双击重置、标签追踪和克制的动态呼吸动效。图表仅做视觉抽样，不会删除任何 CSV 记录或影响平均值。

计算过程中图表更新合并到每约 180ms 一次，减轻主线程压力。原生多线程与数据保存独立于绘图逻辑。完整数据从新计算开始连续写入本地 CSV，可导出。

## 数学定义和边界

目标数字串 `w`、出现序号 `r`、样本数 `N` 可以输入任意正整数长度（受物理内存限制）。无理数依次取 `sqrt(2),sqrt(3),sqrt(5),...`。使用整数平方根逐位长除法生成精确十进制位、KMP 重叠字符串匹配，找目标串第 r 次出现的位置。**没有预设小数位数上限**。未完成样本绝不标记成已找到或平均值的一部分；中止后会明确标记部分样本。

未知是否所有数学目标串都会在每个平方根的小数展开中出现；极端长串或极大出现次数可能持续计算而不完成。后台长时间运行不保证 Android 系统不回收应用，推荐保持前台。
