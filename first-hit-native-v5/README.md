# 数位首现汇聚谱 5.0 · Android 原生实验室

Android 8.0+ 原生 Java 应用，包名 `io.firsthit.studio.v5`。完全使用原生 Canvas 图表，无 WebView。

## 版本 5.0 新功能

- 曲线回放：时间轴拖动、播放/暂停、0.5×/1×/2×/4× 倍速。只作用于绘制，不影响真实统计和 CSV。
- 绘制优化：动态曲线强调、末端光点、绘制节流、数据更新合并。
- 增加经验累计分布图（CDF）与均值稳定度图（按 100 样本相邻检查点差值）。
- 可将当前汇聚曲线保存为 PNG，保留 CSV 导出。
- 最近八次实验的参数和结果摘要存在本地，点按可以恢复参数重新计算。
- 三个快捷预设：数字 1 首次、数字 1 第二次、数字串 14 首次。
- 沿用流畅/全速计算模式、精准整数运算、没有固定小数搜索截止值、图表 16:10、缩放和手势。

## 数学解释与限制

无理数样本为非完全平方整数的平方根，按正整数升序。对于目标连续数字串 w 和指定出现次数 r，逐位精确搜索小数部分中的第 r 次出现，重叠出现仍计入次数。
没有预设的搜索位数限制。但无法保证任意数字串在每一个平方根中都出现，某些任务可能永不结束；未完成样本绝不伪装为已找到的记录。
每 100 个样本的平均值差仅衡量局部稳定程度，并不证明理论极限存在。
单数字理论橘色参考线对应独立等概率十进制数字的等待时间 10*r，不代表平方根序列的严格定理。

## 构建

JDK17 / AGP8.7.3 / Android SDK35。
运行 `bash tests/run.sh` 验证 Java 算术核心。
执行 `gradle :app:assembleDebug` 生成开发测试 APK。
使用 `.github/workflows/build-first-hit-android-v5.yml` 自动编译。
测试 APK 使用调试签名，尚未通过真实手机性能测试。
